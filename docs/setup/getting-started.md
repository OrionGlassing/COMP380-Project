# Getting Started

## Prerequisites

- **Node.js** : required to run the project
- **Expo CLT** :  required to start the development server

## How To Run

### Android
```cmd
npx expo start --clear
# Then press 'a' to open on Android emulator
```

### iOS
```cmd
npx expo start --clear
# Then press 'i' to open on iOS simulator (macOS only)
```

### Web
```cmd
npx expo start --clear
# Then press 'w' to open in browser
```
